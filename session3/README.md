# CIT4040 Session 3

Reading time: 2 minutes per page, plus 10% if the book is over 500 pages.

A book of exactly 500 pages is not fatiguing, because the task says "over 500".

## Run

```
javac Main.java
java Main
```

Output:

```
100 pages -> 200 min
500 pages -> 1000 min
800 pages -> 1760 min
```

`Practice.java` has the class exercises 01-05.
