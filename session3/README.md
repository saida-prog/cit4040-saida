# CIT4040 Session 3

Reading time: 2 minutes per page, plus 10% if the book is over 500 pages.

A book of exactly 500 pages is not fatiguing, because the task says "over 500".

## Run

```
cd session3
javac Main.java
java Main
```

Output:

```
100 pages -> 200 min
500 pages -> 1000 min
800 pages -> 1760 min
```

## Files

- `Main.java` - homework, the `readingTime` method
- `Practice.java` - class exercises 01-05
